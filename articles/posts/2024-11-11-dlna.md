UPnP 是一个多层协议构成的框架体系


UpnP 充分利用了包括 IP、TCP、UDP、HTTP 和 XML 在内的互联网组件。它以 XML 来表达内容，并通过 HTTP 进行传输。在 UpnP 网络中的消息通过采用简单服务发现协议（SSDP）、通用事件通知架构（GENA）和简单对象访问协议（SOAP）来进行格式化。然后消息通过运行于 UDP 上的多播或单播类 HTTP，或是运行于TCP 上的标准 HTTP 进行传输。最终，所有消息均通过 IP 进行传输。
